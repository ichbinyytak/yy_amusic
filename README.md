# Amusic (Apple 音乐纯文本数据库浏览器)

> **定位**：过滤 Apple Music 网页端所有笨重的高清海报、封面图片与多余资源，只提取纯净的歌单、专辑、歌手与曲目数据，实现毫秒级纯文字快速检索与歌单提取，配合 [YY-music](file:///home/yytak/gd/MyFiles/project/YY-music) 极速导入开播。

---

### 一、 核心特性

1. **⚡ 零图片、毫秒级秒开 (Zero-Image & Pure Text)**：
   - 彻底切断官方几百 MB 的图片、动效与臃肿 JS 运行时，直连 Apple 官方底层音乐数据库与 SSR 渲染树；
   - 单次检索与展开通常只需 **100 ~ 200 毫秒**。
2. **✨ 官方最新发布 (/new) 深度全解**：
   - 完整提取新歌精选、本周新发行、歌单已更新、城市榜、巡演等核心板块；
   - **全站去单曲化**：散装单曲板块自动聚合升格为【官方精选合集歌单】，支持穿透官方 Room 加载 100 首完整合集。
3. **🏷️ 官方类别探索 (/search) 100% 真实对齐**：
   - 提取 50 大官方分类专区（国语流行、K-Pop、摇滚、睡眠、减压等）；
   - 点进任意专区，深度抓取 Curator 真实主页，100% 还原官网排布的【焦点推荐】、【官方歌单】、【明星曲目单】与【经典专辑】等板块。
4. **🌍 多地区自由切换**：
   - 支持一键切换中国大陆 (CN)、中国香港 (HK)、中国台湾 (TW)、美国 (US)、日本 (JP)、英国 (GB) 等不同区域曲库。
5. **🎵 深度融合底层音频引擎 (music_underlying)**：
   - **即点即播**：曲目列表直接内置【▶ 播放】与【▶ 播放全部】，无需跳转第三方，全曲直接在线播放；
   - **双核并发竞速**：底层整合 36+ 异构音源（包含车机穿透通道、海棠、念心、网易开放直通及 32+ lx-hub 源），双核并发冲刺，毫秒级出声；
   - **智能容错与零试听**：OpenCC 繁简转换 + 多维加权打分模型自动对齐歌名与歌手，负面词（翻唱/伴奏）一票否决，严格拦截 `<1.5MB` 截断试听与假语音；
   - **毫秒级同步歌词**：原生解析标准时间轴歌词，当前句与下句实时预览跟随；
   - **音源健康监控**：内置音源管理与测速面板，支持一键探活、自适应奖惩重排及与 lx-hub 同步。
6. **📑 一键联动与提取**：
   - **一键复制歌单链接**：生成标准的 Apple Music 官方直链；
   - **一键复制歌曲纯文本**：按 `歌名 - 歌手` 逐行导出整张歌单曲目文本。

### 二、 快速启动

在终端中进入项目目录运行：
```bash
cd /home/yytak/gd/MyFiles/project/Amusic
python3 server.py
```

在浏览器打开：
👉 **`http://127.0.0.1:8088`**
